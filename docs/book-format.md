# Формат книг v1

`public/books/catalog.json` — массив метаданных книг. Поля: `schemaVersion: 1`, `id`, `title`, `author`, `description`,
`originalLanguage`, `translationLanguage`, `difficulty`, `tags`, `cover` (эмодзи), `license`, `source`,
`chapters`. Каждая глава содержит `id`, `title`, `path`, `sentenceCount`. Каталог не содержит текста глав:
`books/demo/chapter-1.json` загружается отдельно относительно Vite base URL `/ReadFold/`.

Глава: `schemaVersion: 1`, `id`, `bookId`, `title`, `paragraphs`. Абзац: `id`, `sentences`.
Предложение: `id`, `text`, `segments`, `hiragana`, `romaji`, `literal`, `natural`, `words`, `kanjiIds`, `grammarIds`.
Необязательное `grammarRoles` — объект `{[grammarId]: string}` с объяснениями роли конструкции именно в этом
предложении. Ключи должны присутствовать в `grammarIds`; в демо описаны все используемые конструкции.
Сегмент `{text, reading?}` задаёт ruby явно; конкатенация `text` всех сегментов обязана совпадать с предложением.
`hiragana` сохраняет орфографию частиц は/へ/を; `romaji` передаёт их произношение wa/e/o.
Каждое вхождение слова: `{wordId, surface, meaning, inflection?, role?}`. Значение и форма относятся к контексту,
а исходная словарная форма хранится отдельно. Повторные вхождения слова в одном предложении допустимы.

`dictionary.json`: `schemaVersion: 1`, `words`, `kanji`, `grammar` — независимые справочники.
Слово: `id`, `surface`, `dictionaryForm`, `reading`, `romaji`, `partOfSpeech`, `meanings`.
Иероглиф: `id`, `character`, `meanings`, `on`, `kun`, `components`, `wordIds`, необязательные `componentMeanings` и `mnemonic`.
`components` — визуальные составляющие для запоминания. `componentMeanings: {[component]: string}` задаёт
русские переводы или ассоциативные образы всех составляющих; если поле указано, его ключи должны точно
совпадать с `components`. `mnemonic` — короткая фраза, связывающая эти образы со значением иероглифа.
Это мнемоника, а не словарные ключи кандзи или утверждение об этимологии. В демо заполнены все иероглифы.
Грамматика: `id`, `title`, `explanation`, `examples: [{text, translation}]`, `relatedIds`.
Примеры грамматики также поддерживают необязательные `hiragana`, `romaji`, `literal`, `natural` и `segments`.
Формат `segments` такой же, как у предложений: непустой массив `{text, reading?}`, восстанавливающий `text`.
В демо все примеры содержат эти слои; старые примеры с `text` и `translation` остаются допустимыми.

Zod-схемы и типы экспортируются из `src/domain/content.ts`. Неизвестные поля запрещены.
ID используют латинские строчные буквы, цифры, точки и дефисы и остаются стабильными при редактуре текста.
Идентификаторы глобально уникальны среди слов, иероглифов и грамматики, поскольку пользовательское
состояние обучения связывается с общим `entityId`. Иероглифы демо используют префикс `kanji.`,
грамматика — `grammar.`, словарные ID слов сохраняются без префикса.
Нельзя менять существующий ID ради изменения заголовка или порядка. Новое несовместимое содержание получает новый ID.
Схемы проверяют уникальность ID и ссылки внутри справочника; `validateChapterReferences` проверяет
ссылки главы, её принадлежность книге и число предложений. Загрузчик должен вызвать обе проверки.

Добавление книги: создать запись каталога, отдельные JSON глав и необходимые словарные записи;
запустить `npm test -- src/domain/content.test.ts`. Все ссылки должны разрешаться, ruby восстанавливать исходный текст.
