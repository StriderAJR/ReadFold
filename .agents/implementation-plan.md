# План реализации и критерии

ТЗ от 12 ноября 2026 реализуется поверх существующей инфраструктуры агентов; её конфигурация сохраняется.
Подтверждены master и remote StriderAJR/ReadFold. Commit/push не выполняются без отдельного указания.

1. Основа: Vite/React/strict TS, Tailwind/shadcn, HashRouter, i18next, CI. HashRouter выбран ради
   прямых ссылок GitHub Pages без изменения сервера; OAuth callback приходит на корень приложения.
2. Независимо: data — Zod, учебный материал, повторения; sync — Dexie и журнал/outbox;
   backend — Supabase/Auth/RLS. Границы файлов согласованы до начала изменений.
3. UI после контрактов: библиотека, читатель, словари, задания, статистика, настройки, аккаунт.
4. Интеграция: локальное сохранение, lazy content, offline shell, синхронизация и экспорт.
5. Проверка: unit/integration, lint, types, production build, Playwright по реальной сборке,
   отдельная проверка безопасности. Внешние настройки фиксируются отдельно от выполненных действий.

Текущая публикация docs сохраняется до явного переключения владельцем Pages на Actions.
PRIVACY/TERMS в public описывают реализованную сборку; исходные документы docs не удаляются.

Доступны роли frontend/data/backend/sync/testing/reviewer. Используются не более трёх субагентов одновременно.
Ограничения окружения и фактические результаты проверок отражаются в README и итоговом отчёте.
