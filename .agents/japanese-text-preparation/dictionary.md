# Новые записи в словаре

[Порядок работы](../japanese-text-preparation.md) · [Формат данных](../book-format.md)

Перед созданием записи проверь весь текущий словарь: переиспользуй существующую запись для того же слова или значения. Не создавай копии из-за другой флексии; словарная форма записывается в `dictionaryForm`, конкретная форма — в `surface` предложения. Существующие записи при необходимости дополняй, сохраняя их ID.

Для каждого нового ID создай исходный файл в `content/ja/dictionary/`: слово добавь в небольшую группу `words/group-NNN.json`, кандзи — в отдельный `kanji/<знак>.json`, грамматику — в отдельную `grammar/<slug>.json`. Добавляй карточку в тот же результат, что и главу; одного ID в предложении недостаточно. Не редактируй собранные файлы в `.local-tools/content/`, `dist/` и `dist_public/`.

Используй ID `ja:word:周り`, `ja:kanji:朝`, `ja:grammar:topic`. Основа слова — японская словарная форма; омонимам с разными значениями или функциями добавляй устойчивое смысловое уточнение: `ja:word:ある:exist`, `ja:word:ある:indefinite`, `ja:word:つく:breath`, `ja:word:つく:rank`, `ja:word:つく:notice`. Не объединяй карточки по написанию или чтению. Уточнение не должно зависеть от книги, номера главы или порядка добавления. Сохраняй уже существующий ID. Полная таблица прежних ID находится в [entity-id-migration.md](../entity-id-migration.md).

## Слова

Для новой записи слова заполни `surface`, `dictionaryForm`, `reading`, `romaji`, `partOfSpeech`, `meanings`. Дай точные русские значения словарной формы, включая значения, нужные в главе. Поля `reading` и `romaji` описывают словарную форму. Контекстное значение и форму отдельно укажи в `wordOccurrences` предложения вместе с обязательными `hiragana` и `romaji` именно этого вхождения. Например, для карточки 行く чтение — いく/iku, а для вхождения 行きます — いきます/ikimasu.

## Кандзи

Для нового кандзи заполни `character`, русские `meanings`, уверенные чтения `on` и `kun`, визуальные составляющие `components` и ссылки `wordIds` на реально существующие слова. Для каждой составляющей дай русский перевод или понятный ассоциативный образ в `componentMeanings`: его ключи должны точно совпадать с `components`. Добавь `mnemonic` — короткую русскую ассоциацию, которая связывает образы составляющих со значением кандзи и помогает его запомнить. Хорошая мнемоника связывает каждый названный образ с целевым значением и легко восстанавливается по одному прочтению. Избегай длинного случайного сюжета, декоративных деталей без связи с частями и повторения определения без подсказки для запоминания. Эти поля необязательны по схеме для совместимости со старыми данными, но для новых карточек нужны как часть подробного учебного разбора.

Не выдумывай составные части, их значения или этимологию. `components` и мнемоника — учебные визуальные подсказки, а не утверждение об историческом происхождении иероглифа. Если надёжный разбор не найден, не подставляй фиктивные части или мнемонику: укажи пробел в отчёте для ручной проверки. Сомнительные чтения и значения тоже помечай в отчёте.

## Грамматика

Заполни отдельный файл `content/ja/dictionary/grammar/<slug>.json` и поля `title`, подробное русское `explanation` (значение, образование и условия употребления), самостоятельный короткий пример в `examples` с русским `translation`, а также `relatedIds`, если есть действительно связанные записи. Общий пример не связывай ID книги, главы или предложения; для него используй оригинальную фразу, не взятую из книги. Если конструкция разбирается в книге, UI покажет соответствующее предложение и `grammarOccurrences[].role` отдельно по адресной ссылке. Объяснение должно различать близкие конструкции, назвать типичную форму и ограничения, но не приписывать форме значение без контекста. Примеры должны показывать именно описанное правило; не дублируй один пример под разными формулировками. По возможности добавь учебные слои `segments`, `hiragana`, `romaji`, `literal` и `natural`; при наличии `segments` их текст должен точно восстанавливать `text` примера. Ссылки `relatedIds` должны разрешаться.

Старые карточки не переписывай массово в ходе миграции формата. Улучшение объяснений, примеров, компонентов и мнемоник — отдельная редакторская задача с небольшими проверяемыми изменениями.
