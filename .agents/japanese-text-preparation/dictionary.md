# Новые записи в словаре

[Порядок работы](../japanese-text-preparation.md) · [Формат данных](../book-format.md)

Перед созданием записи проверь весь текущий словарь: переиспользуй существующую запись для того же слова или значения. Не создавай копии из-за другой флексии; словарная форма записывается в `dictionaryForm`, конкретная форма — в `surface` предложения. Существующие записи при необходимости дополняй, сохраняя их ID.

Ищи адресно по ID, написанию или словарной форме в исходных JSON, затем читай только найденные карточки. Для слова проверь все найденные варианты: одинаковое написание не гарантирует одинакового значения. Не передавай агенту все группы слов целиком. Скрипт пакетного поиска пока не является частью проекта; не ссылайся на несуществующую команду.

Для каждого нового ID создай исходный файл в `content/ja/dictionary/`: слово добавь в группу `words/group-NNN.json` (от 1 до 24 записей), кандзи — в отдельный `kanji/<знак>.json`, грамматику — в отдельную `grammar/<slug>.json`. Исходный файл слов — массив карточек, файл кандзи или грамматики — один объект карточки; обёртка `{schemaVersion, kind, entries}` появляется только при сборке. Добавляй карточку в тот же результат, что и главу; одного ID в предложении недостаточно. Не редактируй собранные файлы в `.local-tools/content/`, `dist/` и `dist_public/`.

Используй ID `ja:word:周り`, `ja:kanji:朝`, `ja:grammar:topic`. Основа слова — японская словарная форма; омонимам с разными значениями или функциями добавляй устойчивое смысловое уточнение: `ja:word:ある:exist`, `ja:word:ある:indefinite`, `ja:word:つく:breath`, `ja:word:つく:rank`, `ja:word:つく:notice`. Не объединяй карточки по написанию или чтению. Уточнение не должно зависеть от книги, номера главы или порядка добавления. Сохраняй уже существующий ID. Полная таблица прежних ID находится в [entity-id-migration.md](../entity-id-migration.md).

## Слова

Для новой записи слова заполни `surface`, `dictionaryForm`, `reading`, `romaji`, `partOfSpeech`, `meanings`. Дай точные русские значения словарной формы, включая значения, нужные в главе. Поля `reading` и `romaji` описывают словарную форму. Контекстное значение и форму отдельно укажи в `wordOccurrences` предложения вместе с обязательными `hiragana` и `romaji` именно этого вхождения. Например, для карточки 行く чтение — いく/iku, а для вхождения 行きます — いきます/ikimasu.

## Кандзи

Агент ссылок на кандзи заполняет для каждого нового знака `character`, точные русские `meanings`, проверенные `on` и `kun` (хотя бы один список непустой) и `wordIds` на существующие слова. На этом этапе оставь `components: []` и не сочиняй мнемонику. Если знак уже есть в словаре как часть с `isMnemonicPartOnly: true`, но теперь встретился в тексте как кандзи, дополни чтения и связи со словами, сними признак части и сохрани его ID. Не создавай вторую карточку. Сомнительные чтения и значения помечай для проверки.

## Зрительные части и мнемоника

Отдельный агент `gpt-6.1-sol` с effort `high` получает **один кандзи на вызов**: его знак, значения и карточку. Не передавай ему текст главы или набор соседних кандзи. Он сам выбирает простые видимые части, заполняет `components`, для каждой — короткий русский образ в `componentMeanings`, затем пишет `mnemonic`, которая связывает **все выбранные части** со значением знака. Части — учебное зрительное разбиение, а не официальный набор ключей и не историческая этимология.

Каждый уникальный знаковый элемент укажи в `components` один раз. Количество и расположение повторов опиши в мнемонике: у `森` часть `木` записана один раз, а мнемоника объясняет, как три дерева образуют лес. Если часть уже есть в `content/ja/dictionary/kanji/`, переиспользуй её карточку без копирования разбора. Для нового знакового элемента сообщи координатору требуемый ID: он ставит отдельное задание на этот знак; карточка `ja:kanji:<знак>` получает `isMnemonicPartOnly: true`, `on: []`, `kun: []`, `wordIds: []` и собственный зрительный разбор в отдельном вызове. Такая карточка не добавляется в `kanjiIds` предложений. Словесные образы вроде «корона» записывай как подписи в `components` и `componentMeanings` текущей карточки, без отдельной карточки знака. Ключи `componentMeanings` должны точно совпадать с `components`; не создавай циклических ссылок.

Мнемоника должна быть короткой, понятной с первого чтения и помогать вспомнить форму и значение. Используй видимое положение частей и их повторы, а не случайный сюжет. Не выдумывай части, их значения или этимологию. Если надёжный зрительный разбор не получается, не подставляй фиктивный образ: оставь вопрос для ручной проверки. Изменяй только назначенную карточку и необходимые новые карточки частей; существующие карточки других кандзи не переписывай ради согласования образов.

## Грамматика

Заполни отдельный файл `content/ja/dictionary/grammar/<slug>.json` и поля `title`, подробное русское `explanation` (значение, образование и условия употребления), самостоятельный короткий пример в `examples` с русским `translation`, а также массив `relatedIds` (пустой, если связанных записей нет). Общий пример не связывай ID книги, главы или предложения; для него используй оригинальную фразу, не взятую из книги. Если конструкция разбирается в книге, UI покажет соответствующее предложение и `grammarOccurrences[].role` отдельно по адресной ссылке. Объяснение должно различать близкие конструкции, назвать типичную форму и ограничения, но не приписывать форме значение без контекста. Примеры должны показывать именно описанное правило; не дублируй один пример под разными формулировками. По возможности добавь учебные слои `segments`, `hiragana`, `romaji`, `literal` и `natural`; при наличии `segments` их текст должен точно восстанавливать `text` примера. Для подсветки японских фрагментов в русском объяснении можно добавить `explanationSegments`; их текст должен точно восстанавливать `explanation`. Ссылки `relatedIds` должны разрешаться.

В новой или используемой в главе карточке грамматики все кандзи, показываемые в японских фрагментах, должны иметь фуригану. Если кандзи есть в `explanation`, обязательно заполни `explanationSegments` и укажи проверенное чтение в сегменте каждого кандзи; их текст должен точно восстанавливать `explanation`. Для каждого примера с кандзи обязательно заполни `segments` с чтением всех кандзи и точным восстановлением `text`; `hiragana` и `romaji` полезны, но не заменяют фуригану над текстом. Групповое чтение нескольких кандзи допустимо, если оно относится ко всей группе. `title` пока не поддерживает сегменты и фуригану, поэтому в новом заголовке пиши японскую форму каной либо давай русское название без кандзи. Если используемая карточка уже имеет заголовок с кандзи, отметь этот пробел в отчёте: текущий формат не позволяет показать там фуригану. Если чтение неоднозначно, отметь его для проверки; не вставляй догадку.

Старые карточки не переписывай массово в ходе миграции формата. Улучшение объяснений, примеров, компонентов и мнемоник — отдельная редакторская задача с небольшими проверяемыми изменениями.
