# Новые записи в словаре

[Порядок работы](../japanese-text-preparation.md) · [Формат данных](../book-format.md)

Перед созданием записи проверь весь текущий словарь: переиспользуй существующую запись для того же слова или значения. Не создавай копии из-за другой флексии; словарная форма записывается в `dictionaryForm`, конкретная форма — в `surface` предложения. Существующие записи при необходимости дополняй, сохраняя их ID.

Для каждого нового ID слова, кандзи и грамматики создай содержательную запись в соответствующем разделе `books/dictionary.json` (`words`, `kanji`, `grammar`) в том же результате, что и главу. Одного ID в предложении недостаточно: карточка должна объяснять сущность независимо от контекста одного предложения.

Новые ID слов должны быть латиницей в нижнем регистре, стабильны и уникальны глобально. Предпочитай простую транслитерацию или ромадзи без диакритики (например, `densha`, `yomu`); кандзи имеют префикс `kanji.`, грамматика — `grammar.`. При совпадении ID добавь уточняющий компонент, не переименовывай уже существующие ID.

## Слова

Для новой записи слова заполни `surface`, `dictionaryForm`, `reading`, `romaji`, `partOfSpeech`, `meanings`. Дай точные русские значения словарной формы, включая значения, нужные в главе; контекстное значение и форму отдельно укажи в `words` предложения.

## Кандзи

Для нового кандзи заполни `character`, русские `meanings`, уверенные чтения `on` и `kun`, визуальные составляющие `components` и ссылки `wordIds` на реально существующие слова. Для каждой составляющей дай русский перевод или понятный ассоциативный образ в `componentMeanings`: его ключи должны точно совпадать с `components`. Добавь `mnemonic` — короткую русскую ассоциацию, которая связывает образы составляющих со значением кандзи и помогает его запомнить. Эти поля необязательны по схеме для совместимости со старыми данными, но для новых карточек нужны как часть подробного учебного разбора.

Не выдумывай составные части, их значения или этимологию. `components` и мнемоника — учебные визуальные подсказки, а не утверждение об историческом происхождении иероглифа. Если надёжный разбор не найден, не подставляй фиктивные части или мнемонику: укажи пробел в отчёте для ручной проверки. Сомнительные чтения и значения тоже помечай в отчёте.

## Грамматика

Заполни `title`, подробное русское `explanation` (значение, образование и употребление), `examples` с примером из главы и русским `translation`, а также `relatedIds`, если есть действительно связанные записи. По возможности добавь к примеру учебные слои `segments`, `hiragana`, `romaji`, `literal` и `natural`; при наличии `segments` их текст должен точно восстанавливать `text` примера. Ссылки `relatedIds` должны разрешаться.
