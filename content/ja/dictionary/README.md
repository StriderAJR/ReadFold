# Части для запоминания

`components.json` — отдельный словарь зрительных образов. Это не словарь кандзи:
у частей нет японских чтений, словарных значений и статуса изучения кандзи.

Каждая запись содержит стабильный `id` (`ja:component:<slug>`), уникальную `form`,
короткое имя образа `name`, простую `mnemonic` и массив дочерних `components`.
Строки в `components` кандзи и частей ссылаются на уникальную `form` общей записи.
Форма может быть знаком, группой черт или понятным названием видимой фигуры.
Одна форма повторно используется во всех разборах; имя и мнемонику правят в одном месте.
`form` служит стабильным ключом ссылки: не переименовывайте и не удаляйте старые формы,
которые могут оставаться в офлайн-кеше. Исправляйте `name` и `mnemonic`; другую форму
добавляйте отдельной записью. `id` также сохраняют неизменным.
Не создавайте для условных образов записи `ja:kanji:*` и не придумывайте им чтения.

При редактировании проверяйте, что история использует показанные части и помогает
вспомнить форму и значение кандзи. Для простого рисунка допустим пустой список частей.
Мнемоника — учебная ассоциация, а не этимология. Старые `componentMeanings` в карточках
сохраняются для совместимости; актуальные имена и мнемоники частей берутся из общего словаря.

`npm run content:build` проверяет ссылки и циклы и публикует словарь частей отдельно
от индекса кандзи. `npm run test:content` проверяет сборку. Генерируемые файлы вручную не редактируют.
